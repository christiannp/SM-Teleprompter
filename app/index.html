    Show lyrics under the teleprompter

    OpenLP has its own web stage view. The stage display shows it underneath the teleprompter strip, so the lyrics follow OpenLP live with nothing extra to install.

    1. Turn on OpenLP's remote

      In OpenLP, open Settings › Configure OpenLP… › Remote Interface. Note the Stage view URL (normally http://localhost:4316/stage).

    2. Point the teleprompter at it

      Open Settings (gear icon) › OpenLP stage view. Tick Show under the teleprompter, paste the URL, choose Below or Behind the TOP bar, then press Save.

    3. Open the stage display

      Click the screen icon (or Open display) and click the display once to go full screen. If Chrome asks to allow access to devices on your local network, choose Allow.

    4. Check it

      The Stage card shows OpenLP stage view connected. Put a song live in OpenLP; the lyric appears under the strip.

    Run OpenLP on this same Mac. The page is served over https, so the browser only lets it load OpenLP from localhost. An address like http://192.168.x.x:4316 will be blocked.
    Not showing? / Change the lyric style
    • “Waiting for OpenLP…”: make sure OpenLP is open and the port matches the one in Remote Interface. Then press Reload in Settings.
    • Custom look: in OpenLP choose Tools › Open Data Folder. Make a folder stages/sm/ with stage.html, stage.css and stage.js (copy OpenLP's custom stage view sample). Then use http://localhost:4316/stage/sm as the URL. This lets you hide OpenLP's own clock and size the lyrics for the area under the strip.

    ProPresenter has no web stage view to embed, so it works the other way round: ProPresenter's stage screen shows the lyrics, and the teleprompter strip is brought into it as live video over NDI.

    1. Let ProPresenter draw the lyrics

      Here, open Settings (gear icon) › OpenLP stage view, untick Show under the teleprompter, press Save, and use TOP mode.

    2. Send the stage display over NDI

      Open the stage display (screen icon) on a spare screen or window. Capture that window as an NDI source, for example with OBS + the DistroAV (NDI) plugin or NDI Tools screen capture.

    3. Add it to ProPresenter

      In ProPresenter, add that NDI source as a Live Video input.

    4. Build a stage layout

      In ProPresenter's stage layout editor, put a shape filled with the Live Video input across the top. Add Current Slide Text (and Next Slide Text) below it, then assign the layout to the stage screen.

    Keep operating from this control strip as usual: messages, countdown and blink go through the NDI feed, and the lyrics follow ProPresenter. NDI adds about 1–2 frames of delay.
